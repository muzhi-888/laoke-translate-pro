# 机翻提示词模板

> 机翻质量 = 提示词质量 × 术语库完整度。下面是可直接复用的框架。

## 一、框架五要素
1. 角色：资深本地化工程师，而非"翻译器"。
2. 硬约束：术语表、输出语言、只输出译文不解释。
3. 风格：去翻译腔、主动优先、拆长句。
4. 保留：代码/专有名词/占位符原样。
5. 样例（few-shot）：1-2 组源→目标对照，立刻对齐风格。

## 二、基础模板
```
你是将英文技术文档译为中文的资深本地化工程师。
术语表（必须严格遵守）：
- cache → 缓存
- throughput → 吞吐量
风格：通顺中文，避免"首先/其次/需要注意的是"等翻译腔；被动转主动；长句拆分；只输出译文。
待译：
{段落}
```

## 三、带样例模板
在基础模板后加：
```
示例：
源：The cache is cleared when the process exits.
译：进程退出时清空缓存。
待译：
{段落}
```

## 四、避坑
- 不要写"请准确翻译"（废话），要写"术语表必须严格遵守"（可验证）。
- 约束要可执行、可检查。
- 分段翻，别整本文档一股脑丢（上下文丢失、术语漂移）。
- 保留源段编号，方便后编辑对照。

## 五、分段策略
- 单段 ≤ 200 词，控制上下文窗口。
- 同章节连续翻，保持术语一致。
- 翻完一段立即后编辑，别攒一堆。

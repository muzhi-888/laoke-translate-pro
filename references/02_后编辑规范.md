# 后编辑规范（去翻译腔）

> 机翻只是初稿，后编辑才是质量分水岭。

## 一、必砍的翻译腔
| 机翻腔 | 改法 |
| --- | --- |
| 首先/其次/综上所述 | 直接说或删 |
| 需要注意的是 | 删或改"务必" |
| 在……方面 | 直说 |
| 我们可以看到 | 删 |
| 通过……的方式 | 直说 |
| 一般情况下 | 删 |
| 对于……来说 | 删 |
| 被……（被动堆） | 转主动 |
| 它（指代不清） | 补主语/省略 |
| 实现……的能力 | 能…… |

## 二、语序与句式
- 西化长定语拆成短句（中文不喜嵌套）。
- 被动转主动，主语前置。
- 连接词冗余（此外/而且/同时）能删则删，用短句衔接。

## 三、逐句自检
每读一句问："母语者会这么说话吗？"不会就改到会。

## 四、保留规则
- 代码、命令、路径、占位符（{{name}}）原样保留。
- 专有名词按术语库（不译的保持原文）。
- 数字单位按目标语习惯（5,000 / 五千）。

## 五、实例对照
- 机翻：「首先，需要注意的是，该接口在 high load 的情况下会超时。」
- 精校：「高负载时该接口会超时。」
- 改动：删冗余连接词、补主语、high load 按术语库定（高负载/原文）。
